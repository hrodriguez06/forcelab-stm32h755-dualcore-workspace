# Board Hardware Documentation

This folder contains hardware design manuals and specifications for the STM32H755 boards:

## 1. Official Evaluation Board Documents
- **[`MB1363_nucleo_h755zi_q_schematics.pdf`](MB1363_nucleo_h755zi_q_schematics.pdf)**: Complete official circuit schematics for the NUCLEO-H755ZI-Q (MB1363). Shows exact wiring of crystal oscillators, Ethernet PHY (LAN8742A), USB OTG connector, user LEDs, ST-LINK VCP UART, and solder bridge (`SBxx`) configurations.
- **[`UM2408_nucleo144_board_manual.pdf`](UM2408_nucleo144_board_manual.pdf)**: Official user manual for STM32H7 Nucleo-144 boards. Details pin headers (ST Zio & Morpho), default jumpers, solder bridges, LEDs, user buttons, Ethernet wiring, and SMPS/LDO power configurations.
- **[`DB_nucleo-h755zi-q_databrief.pdf`](DB_nucleo-h755zi-q_databrief.pdf)**: Official ST Data Brief for the NUCLEO-H755ZI-Q board.
