# DFSDM & DCMI - STM32H755

## 1. Documentation
- `31_digital-filter-for-sigma-delta-modulators-dfsdm.pdf`
- `32_digital-camera-interface-dcmi.pdf`

## 2. Features
- **DFSDM**: Digital Filter for Sigma-Delta Modulators (supports PDM digital microphones, MEMS audio, external ADCs).
- **DCMI**: Digital Camera Interface (supports 8/10/12/14-bit parallel camera sensors, JPEG streaming).
