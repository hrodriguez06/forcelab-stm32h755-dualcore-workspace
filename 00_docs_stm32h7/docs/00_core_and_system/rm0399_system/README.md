# RM0399 System Architecture Chapters

This folder contains the core system architecture chapters extracted from the official ST Reference Manual (RM0399):

- `00_front-matter.pdf`: Table of contents, document scope, and overview.
- `01_documentation-conventions.pdf`: Acronyms, register notation, bit conventions.
- `02_memory-and-bus-architecture.pdf`: Bus matrix, AXI/AHB interconnects, memory mapping.
- `03_ram-ecc-monitoring-ramecc.pdf`: RAM ECC error detection and correction.
- `04_embedded-flash-memory-flash.pdf`: Dual-bank Flash memory architecture, read/write latency.
- `05_secure-memory-management-smm.pdf`: Secure memory areas, isolation between domains.
- `06_art-accelerator.pdf`: Adaptive Real-Time memory accelerator (caches, prefetch).
- `07_power-control-pwr.pdf`: Power supplies (SMPS/LDO), power domains (D1, D2, D3), low-power modes (Run, Sleep, Stop, Standby).
- `08_low-power-d3-domain-application-example.pdf`: Application examples running from D3 low-power domain.
- `14_block-interconnect.pdf`: Peripheral interconnect matrix, event and trigger routing.
- `63_debug-infrastructure.pdf`: SWD/JTAG debug, trace (ETM), breakpoint units.
- `64_device-electronic-signature.pdf`: Unique device ID (UID, 96 bits), Flash memory size.
- `65_important-security-notice.pdf`: Security recommendations.
- `66_revision-history.pdf`: Document revisions and changes.
